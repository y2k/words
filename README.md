# Words

## Ключ релизной подписи

Локальная резервная копия keystore и паролей (`credentials.json`) находится
в `~/.local/share/words/signing/`. В репозитории хранится только зашифрованный
ключ: `signing/release.jks.gpg`.

Сохраните независимую резервную копию: потеря ключа лишит возможности выпускать
совместимые обновления. Значения GitHub Secrets нельзя прочитать обратно.

## Расшифровка ошибок релизов

Для каждого релиза сохраняйте артефакт Actions `r8-mapping-<release tag>`
до истечения срока его хранения. Внутри — `mapping.txt` для расшифровки
обфусцированных stack trace. Нужен mapping именно той сборки, в которой
возникла ошибка; повторная сборка того же исходного кода не заменяет его.
